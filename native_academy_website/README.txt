NATIVE ACADEMY TRUST WEBSITE — PROTOTYPE
=========================================

FILES
- index.html: the responsive website. Open it in a browser to preview.
- README.txt: these instructions.

WHAT WORKS
- Responsive layout for mobile and desktop
- Navigation links and mobile menu
- Sections for school information, programmes, gallery, testimonials, news and contact
- Enquiry form validates required fields and prepares a WhatsApp message to 077 433 8655
- WhatsApp contact links for 077 433 8655 and 071 497 8804

IMPORTANT BEFORE PUBLISHING
1. Confirm the addresses, contact numbers, classes/programmes and school claims.
2. Replace sample gallery photos with approved school photos. The current demo photos are loaded from Unsplash and require an internet connection.
3. Replace placeholder testimonials with genuine comments used with permission.
4. Replace the example payment email (nativeacademy@example.com) with an official school email.
5. Online payments are NOT connected. Do not accept card or bank details through this prototype. To enable payments, choose a reputable provider available in Zimbabwe and integrate its hosted checkout/payment link after the school's merchant account is verified.
6. The enquiry form opens WhatsApp; it does not save enquiries in a database or email them automatically. A production registration system needs a secure backend and privacy notice.
7. Add the school's privacy policy and any relevant child safeguarding/data protection notices before collecting learner information.

FREE PUBLISHING OPTION: GITHUB PAGES
1. Create or sign in to a GitHub account at https://github.com/
2. Create a new public repository named native-academy-trust-website.
3. Upload index.html to the repository's root (top-level) folder.
4. Open the repository's Settings → Pages.
5. Under Build and deployment, choose Deploy from a branch; choose the main branch and /(root), then Save.
6. Wait for GitHub Pages to publish. The site URL will look like https://YOUR-USERNAME.github.io/native-academy-trust-website/
7. Open the URL on a phone and computer and test all links and the enquiry form.

OTHER FREE OPTION: NETLIFY
1. Visit https://www.netlify.com/ and create an account.
2. Use the manual deploy / drag-and-drop option and upload the folder containing index.html (or drag the HTML file if prompted).
3. Netlify will provide a public preview URL. Follow its current dashboard prompts to publish.
4. Test the published site on a phone and computer.

NOTES
- Free hosting providers may change their setup steps and terms.
- A custom .com or .co.zw domain usually costs extra.
- This is a front-end prototype, not a complete school management system.
